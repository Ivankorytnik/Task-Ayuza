# plans/

Планы задач Task-Ayuza: фазы, критерии приёмки, решения ревью и checkpoints.

- Один файл на задачу: `ГГГГ-ММ-ДД-<краткое-имя>.md`, по образцу `TEMPLATE.md`.
- Существующий план дополняется, новый не создаётся для той же задачи.
- Checkpoint фиксирует только реальные результаты проверок.
- Секреты и персональные данные сюда не пишутся.
