# Task-Ayuza | Демо-прототип (DEMO-MVP-1)
Статический PWA без бэкенда. Только синтетические данные, хранение в localStorage. Не заменяет M01.2 и не является приёмкой F01-F37.

Запуск: открыть `demo/index.html` (для PWA и service worker нужен http, например `python3 -m http.server -d demo`).
Проверка логики: `node demo/test_logic.js`.

Показывает: Мои задачи, Все задачи, Kanban (перетаскивание меняет статус вручную), Блокеры (создать, снять, открыть снова), Внешние ожидания, фильтры, форму задачи по ТЗ п.5, зависимости «A блокирует B» без самоссылок, дублей и циклов, диктовку.
Ограничение диктовки: в демо используется браузерный SpeechRecognition (в Chrome аудио обрабатывает сервис браузера); по ТЗ п.5.1 в продукте только локальный whisper.cpp на своём сервере.
