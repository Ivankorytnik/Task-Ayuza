- Прямые зависимости установлены в отдельное venv по requirements-m01.txt: SQLAlchemy 2.0.50, Alembic 1.18.4, psycopg/psycopg-binary 3.2.12, FastAPI 0.128.2, uvicorn 0.40.0, pytest 9.0.2.
- Системный apt update недоступен: ошибка каталога lists/partial. Пакеты PostgreSQL взяты из Debian trixie, SHA-256 сверены с Packages.xz и распакованы локально без системной установки. Сервер и libpq проверены запуском.
- Каждый полный прогон создаёт новый временный PGDATA через initdb, проверяет каталог и исходные postgres/template0/template1, затем создаёт пустую task_ayuza_test. Администратор и три роли имеют случайные одноразовые пароли вне Git. Только 127.0.0.1:55439, SCRAM; Unix-сокеты отключены из-за ограничения среды. Рабочие подключения не используются.
- После прогона сервер остановлен, временный кластер и пароли удалены. Синтетика существует только в одноразовом контуре.

Команда после установки зависимостей и PostgreSQL (путь к bin задаётся явно):

```bash
python tests/run_m01_acceptance.py --pg-bin /path/to/postgresql/17/bin
```
